## 2. ПРОБЛЕМА «МАЛО ПОКАЗОВ»

### Что это
Яндекс присваивает статус «мало показов» ключевым фразам с очень низким прогнозом показов (~5-10/мес). Такие фразы **перестают показывать объявления** даже при точном совпадении запроса.

### Масштаб проблемы

| Частотность | Маршрутов | % | Риск |
|---|---|---|---|
| 0-5 | 561 | 38.0% | **Критический** — фразы не будут показываться |
| 5-10 | 316 | 21.4% | **Высокий** — могут получить статус |
| 10-50 | 400 | 27.1% | Умеренный |
| 50-200 | 132 | 8.9% | Низкий |
| 200+ | 67 | 4.5% | Нет риска |

### Как бороться

**Стратегия 1: Группировка ключей (основная)**
- Объединять маршруты с низкой частотностью в одну группу объявлений
- Группировать по направлению: "Москва — [все города Тульской области]" в одной группе
- Суммарная частотность группы должна быть > 50

**Стратегия 2: Широкое соответствие**
- Для маршрутов с freq < 10 использовать широкое соответствие вместо точного
- Пример: `такси Москва Тамбов` вместо `"такси Москва Тамбов"`
- Добавить минус-слова для фильтрации нерелевантного трафика

**Стратегия 3: Шаблоны объявлений**
- Использовать {keyword:подстановка} в заголовках
- Одно объявление на группу маршрутов, автоподстановка города

**Стратегия 4: Дополнительные ключи**
- К каждому маршруту добавлять синонимы:
  - "такси [Город1] [Город2]"
  - "трансфер [Город1] [Город2]"
  - "междугороднее такси [Город1] [Город2]"
  - "[Город1] [Город2] такси цена"
  - "заказать такси [Город1] [Город2]"
- Это повышает суммарную частотность группы

## 4. ГРУППИРОВКА МАРШРУТОВ (против «мало показов»)

### Принцип группировки
Маршруты из одного города-хаба объединяются в одну группу объявлений:

**Пример: Группа "Казань → Татарстан"**
```
Ключи:
  такси Казань Лениногорск          (freq 42076)
  такси Казань Елабуга              (freq 42076)
  такси Казань Альметьевск          (freq  479)
  такси Казань Нижнекамск           (freq  474)
  такси Казань Набережные Челны     (freq  464)
  такси Казань Бугульма             (freq  459)
  такси Казань Азнакаево            (freq  204)
  + трансфер/междугороднее для каждого

Объявление:
  Заголовок: Такси {keyword:Казань — межгород} от 6 500₽
  Текст: Комфортная поездка. Фиксированная цена. Подача 30 мин.
  Ссылка: https://city2city.ru/{keyword_url}.html
```

### Правила группировки

| Freq маршрута | Группировка | Тип соответствия |
|---|---|---|
| > 200 | Отдельная группа (1 маршрут) | Точное и фразовое |
| 50-200 | 2-3 маршрута в группе | Фразовое |
| 10-50 | 5-10 маршрутов в группе | Фразовое |
| < 10 | Все из одного хаба в одну группу | Широкое |

## 8. ЧЕКЛИСТ ЗАПУСКА

### До запуска
- [ ] Загрузить маршруты в Директ (CSV/XLS)
- [ ] Настроить UTM-метки: `?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign}&utm_content={ad_id}`
- [ ] Настроить цели в Метрике (заказ, звонок, форма)
- [ ] Создать аудиторию ретаргетинга
- [ ] Проверить посадочные страницы (цена, форма заказа, телефон)

### Первая неделя
- [ ] Запустить HOT кампании (Донецк + Урал)
- [ ] Мониторить CTR, CPC, позиции
- [ ] Отключить ключи со статусом «мало показов»
- [ ] Расширить ключи для проблемных групп

### Вторая неделя
- [ ] Запустить MAIN кампании (ПФО, ЦФО, ЮФО)
- [ ] A/B тест заголовков
- [ ] Настроить корректировки ставок (мобильные, время суток)

### Месяц 1
- [ ] Запустить оставшиеся кампании (СФО, СЗФО, ДФО, СКФО)
- [ ] Проанализировать конверсии по маршрутам
- [ ] Отключить неконверсионные маршруты (CPA > порога)
- [ ] Масштабировать конверсионные маршруты

### Ежемесячно
- [ ] Анализ поисковых запросов → новые минус-слова
- [ ] Обновление ставок по ROI
- [ ] Добавление новых маршрутов (из P2 после заполнения расстояний)
