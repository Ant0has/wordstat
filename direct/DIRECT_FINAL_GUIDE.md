## 2. ПРОБЛЕМА «МАЛО ПОКАЗОВ» И ТРИ СТРАТЕГИИ

### Масштаб проблемы

Яндекс присваивает статус «мало показов» группам, ключи которых суммарно набирают менее ~10 показов/мес. Такие группы **полностью выключаются из показа**.

| Категория | Критерий | Маршрутов | Доля | Стратегия |
|---|---|---:|---:|---|
| Высокая частотность | Оба города degree 50+ | 633 | 29% | **А:** Точные ключи |
| Средняя частотность | Один 50+, второй 15–49 | 243 | 11% | **А:** Точные ключи |
| Низкая частотность | Оба 15–49, или 50+ и 5–14 | 463 | 22% | **Б:** Группировка по городу |
| Нулевая частотность | Хотя бы один город degree <5 | 819 | 38% | **В:** Динамические объявления |

### Стратегия А: Точные ключевые фразы (876 маршрутов)

Для пар крупных городов, где запрос «такси [Город А] [Город Б]» имеет реальную частотность (≥10 показов/мес). Каждый маршрут = отдельная группа объявлений с 5–8 ключевыми фразами.

**Шаблон фраз:**
1. `такси {А} {Б}`
2. `трансфер {А} {Б}`
3. `межгород {А} {Б}`
4. `{А} {Б} такси цена`
5. `заказать такси {А} {Б}`
6. `междугороднее такси {А} {Б}`
7. `перевозка {А} {Б}`
8. `машина {А} {Б}`

### Стратегия Б: Группировка по городу отправления (463 маршрута)

Все маршруты из одного города объединяются в одну группу. **59 групп объявлений.**

**Шаблон фраз для группы города {А}:**
1. `междугороднее такси {А}`
2. `такси межгород {А}`
3. `трансфер из {А}`
4. `такси {А} межгород цена`
5. `заказать такси из {А}`
6. `перевозка из {А}`
7. `междугородний трансфер {А}`
8. `такси из {А} в другой город`

### Стратегия В: Динамические объявления по фиду (819 маршрутов)

Для нишевых маршрутов, где любой ручной ключ даст «мало показов». Яндекс сам подбирает фразы по содержимому страницы.

**Настройка:**
1. Кампания типа «Динамические объявления»
2. Источник: фид URL (CSV с 819 адресами)
3. Фильтр: страницы с ценой ≥ 10,000₽
4. Заголовок: автоматический (Яндекс подставит из H1)
5. Текст: «Фиксированная цена. Подача от 30 мин. Оплата картой.»
6. Стратегия: «Максимум кликов» с недельным бюджетом

## 9. ОПТИМИЗАЦИЯ ПОСЛЕ ЗАПУСКА

### 9.1. Первая неделя: чек-лист

1. **Показы > 100/день** — если меньше: расширить фразы или повысить ставку
2. **Нет статуса «Мало показов»** — если есть: объединить группу с соседней или перевести в групповые
3. **CTR > 3% на поиске** — если ниже: переписать заголовки, добавить цену
4. **Конверсий ≥10/нед** — если меньше: временно «Максимум кликов»
5. **Отказы < 30%** — если выше: проблема лендинга, не рекламы

### 9.2. Борьба с «Мало показов» (мониторинг)

Еженедельно проверять статус групп. Если группа получила «Мало показов»:

1. Перенести маршрут из Стратегии А (точные) → Стратегия Б (групповые)
2. Если групповая тоже «мало показов» → Стратегия В (динамика по фиду)
3. Добавить широкие фразы: «такси [город] недорого», «межгород [город] заказать»
4. Проверить, не блокируют ли минус-слова (отчёт «Поисковые запросы»)

### 9.3. LP-оптимизация бюджета (с месяца 2)

После 4 недель данных — линейное программирование:

**max Σ(Vᵢ / CPLᵢ)  при  ΣVᵢ ≤ B,  Vᵢ ≥ 10 × CPAᵢ**

Реализация: Python + scipy.optimize.linprog, пересчёт каждый понедельник.
